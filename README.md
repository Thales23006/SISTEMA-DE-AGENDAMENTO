# SISTEMA-DE-AGENDAMENTO
Este é um MVP(Minimum Viable Product) desenvolvido em python tem a proposta de fornecer uma solução para  gestão de atendimentos de beleza(em especial para quem é manicure e pedicure). Esse software surgiu da necessidade de entregar um sistema simples  para minha mãe que a ajudasse no dia-dia a organizar seus atendimentos e clientes. O sistema foca em simplicidade, usabilidade e persistência de dados.

🛠️ O que eu utilizei:
Linguagem: Python

Interface: Streamlit (para uma Web App rápida e responsiva)

Banco de Dados: SQLite (armazenamento local dos agendamentos)

Deploy: Streamlit Community Cloud

🚀 Funcionalidades:
Cadastro rápido de clientes e serviços.

Seleção de data e horário.

Visualização em tempo real da agenda.

Opção de exclusão de registros para manter a lista atualizada.
