# SISTEMA-DE-AGENDAMENTO
Este é um MVP(Minimum Viable Product) desenvolvido em python tem a proposta de fornecer uma solução para  gestão de atendimentos de beleza(em especial para quem é manicure e pedicure). Esse software surgiu da necessidade de entregar um sistema simples  para minha mãe que a ajudasse no dia-dia a organizar seus atendimentos.
